# 🌐 مشروع استعراض البيانات ثلاثي الأبعاد (Data Explainer 3D)

مشروع ويب تفاعلي ثلاثي الأبعاد مصمم بلغات HTML, Tailwind CSS, JavaScript ومكتبة Three.js، يهدف إلى استعراض وشرح مفاهيم البيانات وأنواعها ومصادرها وقيمتها بناءً على العرض التقديمي الأكاديمي.

---

## 🚀 مميزات المشروع
- **خلفية ثلاثية الأبعاد تفاعلية:** شبكة جزيئات وعقد بيانات متحركة باستخدام Three.js تتفاعل مع حركة الماوس.
- **تصميم زجاجي عصري (Glassmorphism):** واجهة مستخدم أنيقة متوافقة مع جميع الأجهزة باستخدام Tailwind CSS.
- **شرح مفصل للمحتوى:** يغطي تعريف البيانات، أنواعها (شخصية، مالية، صحية، رقمية)، مصادرها، وأمثلة من الحياة اليومية.
- **محاكي مسار البيانات (Data Pipeline Simulator):** أداة تفاعلية تشرح خطوات تحويل البيانات الخام إلى قرارات استراتيجية.

---

## 🛠️ التقنيات المستخدمة
- HTML5 / CSS3
- Tailwind CSS
- JavaScript (ES6)
- Three.js (للرسومات ثلاثية الأبعاد)
- FontAwesome & Google Fonts (Cairo)

---

## 👩‍💻 إعداد وتشغيل المشروع محلياً
1. قومي بتحميل الملف أو سحبه بصيغة `index.html`.
2. افتحي الملف باستخدام أي متصفح حديث (مثل Google Chrome أو Edge).
3. استمتعي بالتجربة التفاعلية واستعراض محتوى البيانات!
